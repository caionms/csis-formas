Para executar o projeto, é necessário ter python 3.12 ou superior instalado na máquina. 
Com python instalado, pode-se instalar o poetry com:

- `pip install poetry`

Em seguida, pode-se instalar as dependências do projeto com o poetry com:

- `poetry install`

Por fim, para executar o OCR, é necessário instalar a versão do paddlepaddle correspondente ao seu sistema e especificações, para isso, basta seguir o tutorial em https://www.paddlepaddle.org.cn/en/install/quick?docurl=/documentation/docs/en/install/pip/macos-pip_en.html
